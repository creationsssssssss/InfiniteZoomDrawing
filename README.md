# InfiniteZoomDrawing
This website is about drawing but you can zoom infinitely and basically you can also draw infinitely but the drawing feature is buggy and may ruin stuff if you zoom in or out too far.

There Many features (Here are some additional features):
- Link Drawings/Objects/Texts
- Bookmarks
- More Drawings (On Accounts)
- Zoomspeed
- Camerarotation
- Objects/Text/Photo/Files
- Lasso
- Tip: Round/Block
- Bar: Scroll/Wrap
- And More but there will be updates…
